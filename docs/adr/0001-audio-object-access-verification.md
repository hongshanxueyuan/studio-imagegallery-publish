# 音频验收只证明对象可访问，不证明字节完整

Studio 的 `get_audios` 只能证明 Gallery 存在音频文档绑定，不能证明 OSS 对象存在；因此验收要求恰好一条绑定，并调用 `get_audio_download_url`。对其 GET 签名地址发送 `Range: bytes=0-0`：返回 200/206 且读到字节，记为“对象可访问”；404/`NoSuchKey` 记为失败；其他状态、网络或签名错误、空响应记为无法确认。OSS 预签名地址按 HTTP 方法签名，因此 GET 地址不能用于 HEAD；CORS OPTIONS 也不能验证对象是否存在。

批次记录保存本地大小和 SHA-256、上传 key 与下载期望 key 的路径、bucket/region、audio ID、分片数与完成结果，以及响应长度等可用信息；不保存凭证或完整签名 URL。两个 key 不一致只作诊断，不改变验收结果。响应长度不与本地大小比较，因此“对象可访问”不代表 MP3 完整，也不代表其字节与本地文件一致。
