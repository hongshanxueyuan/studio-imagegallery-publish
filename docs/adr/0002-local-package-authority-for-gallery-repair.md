# 本地课程包是其所含 ImageGallery 小节的权威来源

用户只要求检查时，流程只读；只有明确要求“检查并修复”时，才重建本地素材或写入 Studio。对本地包列出的章节，以本地包为准；包外的 Studio 章节不处理。已有 operation-file 时先核对它对应的课程；没有 operation-file 时，优先按课程和小节 ID 映射，标题仅在唯一匹配时兜底。小节或 Gallery 目标不唯一时，停止该目标。

检查整个 Gallery，包括图片顺序与引用、字幕文本和时间、音频绑定与对象可访问性，以及本地素材是否齐全。修复时以本地包整体替换 Gallery；Studio 小节中没有 Gallery 时创建，再核对 Gallery 内容和小节正式发布状态。若本地 Gallery 清单或素材不完整，调用 `ppt-to-imagesgallery` 的单小节修复逻辑；仅在本地重建完整后才推送，无法完成时停止并报告。

沿用现有的小节结构规则：直属组件都可识别时，保留修复后的 Gallery 和唯一的“本节要点”，并移除其它直属组件；结构有歧义时保留现场，仍尝试发布小节，复核后报告尚未解决的结构问题。
