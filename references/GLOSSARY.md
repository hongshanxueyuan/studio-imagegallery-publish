# Studio ImageGallery Publishing

本上下文描述将本地 ImagesGallery 内容替换到 Studio 小节并核对其发布结果时使用的领域词汇。

## Language

**发布执行结果**：本次目标 Gallery 内容写入及所属小节发布操作的执行状态。它与批次审核结果分别记录。
_Avoid_: 推送完整性, 审核通过

**批次审核结果**：对批次内各 Gallery 最终 Studio 状态的核验结果，区分通过、确认不一致和无法确认；它不改变发布执行结果。
_Avoid_: 发布完成, 发布日志

**推送完整性**：本地 Gallery 内容、目标小节组件结构和正式发布状态均符合本次预期时的最终状态，是批次审核结果的一种通过条件。
_Avoid_: 请求成功, 发布执行结果

**替换目标组件**：Studio 小节中需要由本批 Gallery 替代的既有内容组件。安全清理可识别本批 Gallery 与本节要点后，移除其余直接子组件。
_Avoid_: 旧组件, 待删组件

**文字讲解组件**：Studio 小节中承载正文讲解的 HTML 组件；HTML 类型的 Gallery 替换流程以它为替换目标。
_Avoid_: 正文 HTML, 第一个 HTML

**本节要点组件**：Studio 小节中独立呈现本节摘要的 HTML 组件；它保留在课程结构中，不作为 NLM Gallery 页面或配音的来源。
_Avoid_: 摘要页, 要点幻灯片

**纵向组件快照**：某一时点 Studio vertical 的直接子组件清单，记录组件数量、类型、定位信息和顺序。
_Avoid_: 组件数量记录, 页面快照

**小节正式发布状态**：Studio 中当前保存的小节内容是否已同步到学员可见版本的状态。已有公开版本不代表当前编辑内容也已发布；仍有未发布改动时，当前内容的发布尚未完成。
_Avoid_: 发布成功日志, 已保存状态

**状态对账**：将一次发布的预期结果与 Studio 当前实际状态比较，确认本次内容已生效且没有未发布改动。
_Avoid_: 重跑, 重试日志

**批次结果校验**：批次内所有章节的发布尝试结束后，将各章节的预期内容与 Studio 实际课程状态比较，并形成整体结果。
_Avoid_: 逐章节发布确认

**无人值守批次发布**：按顺序完成批次内各章节的发布工作；某个章节失败时记录问题并继续其他可独立执行的章节，最终统一报告。
_Avoid_: 中途人工决策, 逐章节确认
