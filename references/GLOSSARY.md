# Studio ImageGallery Publishing

本上下文描述将本地 ImagesGallery 内容替换到 Studio 小节并核对其发布结果时使用的领域词汇。

## Language

**替换目标组件**：Studio 小节中按本地内容类型确定、需要被新 Gallery 替换的既有组件。它必须能在该小节当前结构中被唯一识别。
_Avoid_: 旧组件, 待删组件

**文字讲解组件**：Studio 小节中承载正文讲解的 HTML 组件；HTML 类型的 Gallery 替换流程以它为替换目标。
_Avoid_: 正文 HTML, 第一个 HTML

**本节要点组件**：Studio 小节中独立呈现本节摘要的 HTML 组件；它保留在课程结构中，不作为 NLM Gallery 页面或配音的来源。
_Avoid_: 摘要页, 要点幻灯片

**纵向组件快照**：某一时点 Studio vertical 的直接子组件清单，记录组件数量、类型、定位信息和顺序。
_Avoid_: 组件数量记录, 页面快照

**小节正式发布状态**：Studio 对一个小节已发布版本的明确状态；发布操作的调用结果本身不代表该状态。
_Avoid_: 发布成功日志, 已保存状态

**状态对账**：将一次发布的预期结果与实际状态比较，以确认发布是否生效。
_Avoid_: 重跑, 重试日志

**批次结果校验**：批次内所有章节的发布尝试结束后，将各章节的预期内容与 Studio 实际课程状态比较，并形成整体结果。
_Avoid_: 逐章节发布确认

**无人值守批次发布**：按顺序完成批次内各章节的发布工作；某个章节失败时记录问题并继续其他可独立执行的章节，最终统一报告。
_Avoid_: 中途人工决策, 逐章节确认
